# Thimble

This repo is a demonstration of a super small iOS app and also the capabilities of Claude.

It's always driven me a bit crazy how big app binaries are. So I got Claude to write a Bluesky client for iOS whose download is about 30 KB.

It built everything, including the slide deck presentation. This is all Claude, apart from me giving it a few prompts.
My favorite was I suggested it use a byte code and interpreter. Claude invented the interpreted language you'll see here.
